# 💙 ELDORA — Elder Care & Caretaker Platform

**Making elderly care more accessible, convenient, and compassionate.**

ELDORA is a caretaker platform concept designed to help families explore elderly care and caretaker services more conveniently. The project aims to simplify the process of finding care support while making elderly well-being a priority.

## 🌟 About the Project

As families balance busy schedules and caregiving responsibilities, finding suitable care support can be challenging. ELDORA aims to provide a digital platform that brings elderly care services and families closer together.

The project is being developed as a hands-on learning experience focused on building a practical, real-world web application.

## 🎯 Project Goals

- 👵 Make elderly care services easier to access.
- 🤝 Help families connect with caretaker services.
- 📅 Support a convenient care-service booking experience.
- 💙 Encourage compassionate, reliable elderly care.
- 🏡 Explore ways to make everyday care management simpler.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/jiyajiyabhola888-blip/Eldora.git
cd Eldora
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the environment

**Windows — Git Bash:**

```bash
source venv/Scripts/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the backend

Navigate to the backend folder and run the FastAPI application using the appropriate module and app name configured in the project.

For example, if the entry file is `main.py` and the FastAPI instance is named `app`:

```bash
uvicorn main:app --reload
```

Open the interactive API documentation at:

`http://127.0.0.1:8000/docs`
